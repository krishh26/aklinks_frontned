Referral Program Configuration

Manage your referral program settings including commission rates, bonuses, and payout thresholds. These settings will affect how users earn from referrals.

Toggle to enable or disable the referral program for all users.
Percentage of referred user's earnings that will be paid as commission (0-100%).
Minimum amount required before referral earnings can be withdrawn.
One-time bonus amount given to the referrer when a new user signs up.
Maximum number of referrals allowed per user. Set to 0 for unlimited referrals.
Base URL for referral links. The referral code will be appended to this prefix.

ℹ️ Information

  • Commission rate determines the percentage of earnings shared with referrers.
  • Minimum payout is the threshold before users can withdraw referral earnings.
  • Referral bonus is a one-time reward when someone signs up using your link.
  • Setting max referrals to 0 allows unlimited referrals per user.
  • Changes will be applied immediately after saving.
  • Only administrators can modify these settings.
